# Five-minute demo

Practice with the prepared project before the interview. Use page names from [the page catalog](../screenshots.md), not an assumed tab position. Keep the same country/segment filter until explicitly resetting it. The architecture and quality evidence are open in separate document tabs.

| Time | View and exact talking point |
|---|---|
| 0:00–0:30 | Executive Overview: “The problem is fragmented customer information. I built a portfolio platform to connect customer understanding, opportunities and measurement. The original snapshot is limited; behavioral and experiment data are synthetic.” |
| 0:30–1:00 | Customer Profile then Digital Engagement: “Customer 360 joins the accepted population to product depth, payroll and activity. Missing values remain visible; a value proxy is not CLV.” Show one aggregate country filter, then reset. |
| 1:00–1:40 | Primary Banking then Campaigns: “This readiness funnel identifies where to investigate, not a causal transition. Campaign rates need an explicit contact denominator and mature conversion window.” |
| 1:40–2:35 | Predictive Analytics then Next Best Action: “Four demo models score eligible customers. The payroll baseline is constant and holdout performance is weak. Contact policy and ownership take priority over model score.” |
| 2:35–3:35 | Experimentation: select Payroll, then Travel, then Digital Re-engagement. “Payroll has a significant estimate but misses planned sample; travel fails a guardrail; re-engagement wins only in this simulation. Prediction and causal measurement answer different questions.” |
| 3:35–4:10 | Simplified architecture: “Preserve, validate, model, analyze, explain. The local DAG makes publication auditable; cloud assets remain references.” |
| 4:10–4:40 | Data Quality and final health: “1,999 source rows reconcile to 1,439 accepted plus 560 quarantined. Critical failures stop publication. Warnings are visible.” |
| 4:40–5:00 | Close on the payroll business case: “With governed real data, I would validate eligibility, run a powered randomized trial and scale only if incremental conversion and customer guardrails support it.” |
