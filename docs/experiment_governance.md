# Experiment governance and QA

Specifications in `experiments/EXP*.yaml` define hypothesis, owner, dates, population, exclusions, control, treatment, primary/secondary metrics, guardrails, MDE, alpha/power and explicit synthetic data-generating assumptions. APPROVED means approved **for local simulation only**. No actual campaign is launched.

Lifecycle: DRAFT → APPROVED → RUNNING → COMPLETED → ANALYZED, or STOPPED with preserved evidence. A real system must authenticate approvals and prevent analysis of immature outcomes. The simulator requires an approved specification, valid dates and a completed outcome horizon before generating/analysing. Exposure/assignment/conversion fields carry deterministic seed and synthetic labels.

Assignment uses a seeded balanced random permutation of eligible sorted customer keys. Enrollment is evaluated before assignment using dated features, no prior target ownership, observed offer eligibility, contact permissions/caps and a stable 5% persistent holdout. Outcome generation is separate from assignment with explicit baseline/effect parameters; exposure can be incomplete. Control in the re-engagement trial receives no simulated campaign and is not incorrectly marked as missing exposure. Outcomes follow assignment inside the specified window; no post-assignment user removal changes ITT denominators.

QA checks unique customer/experiment assignment, valid variants, assignment/exposure chronology, matched outcome flag/date, mature conversion windows, holdout exclusion, exposure completeness and SRM. Structural corruption blocks analytical publication. Excess missing exposure invalidates interpretation and produces INCONCLUSIVE; the incident result can remain visible without being treated as a valid effect. A cross-variant duplicate or chronology violation cannot be hidden by a favorable conversion rate.

Balance diagnostics compare pre-assignment engagement and fixed master-profile audit proxies for age/country/balance/credit/value. Those financial/profile values have no historical versions and are not claimed to be historically observed covariates. Standardized differences and group proportions are diagnostics, not a guarantee that randomization succeeded or that results generalize. Simultaneous conflicting experiment windows are checked by customer overlap and invalidate interpretation. Existing unrelated synthetic campaigns remain a documented background-exposure limitation; randomization does not magically remove interference, seasonality or operational contamination.

Guardrails include unsubscribe/complaint changes, NPS proxy change and cost per assigned treatment customer. Point-threshold guardrails in this small demonstration are not a complete sequential safety-monitoring design. The persistent holdout is not used as a post-hoc randomized control for old campaigns; future long-term evaluation would need controlled exposure and consistent consent/retention policy.
