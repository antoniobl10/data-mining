# Digital business interview concepts

| Concept | Interview-ready explanation |
|---|---|
| Funnel / conversion / drop-off | A defined population progresses through nested or timestamp-ordered stages; conversion and abandonment need consistent denominators and windows. |
| Cohort / retention | Customers sharing an observed starting event are followed across observed periods using one explicit activity/ownership definition. |
| Journey | The sequence and timing of observed actions within sessions or before an outcome, not invented intent. |
| Lifecycle | Explainable relationship/activity stages with documented rules, transitions and uncertainty. |
| Engagement | A behavior-based proxy with stated inputs/windows; more events do not prove more customer value. |
| Primary bank | A relationship proxy combining payroll, account/product depth, engagement and services; not verified exclusivity. |
| A/B test / control / treatment | Randomized comparison of defined policies with pre-specified outcomes, QA and guardrails. |
| P-value / interval | Null incompatibility / estimation uncertainty; neither automatically establishes business usefulness. |
| Incrementality / uplift | Difference caused by an action; average trial effects differ from individual treatment-effect predictions. |
| Propensity | Predicted chance of an outcome under observed conditions; a high score is not evidence that contact helps. |
| Attribution | A rule allocating conversion credit to prior touches; it is not a causal experiment. |
| Campaign ROI | Value minus cost divided by cost; here value is synthetic and not actual bank margin or CLV. |

Discuss guardrails, SRM, adequate planned sample size, contamination, maturity, repeated peeking, seasonality and consent whenever interpreting experiment results. State whether evidence is observational, randomized simulation, or a properly executed real-world experiment.
