# Current report specification

The active enhanced PBIR project contains Executive Overview, Customer Profile, Financial Analysis, Segmentation and Customer Explorer. Hidden supporting pages provide Customer Detail, Country Tooltip, Segment Tooltip and Data Quality. The generated inventory is [model/report_inventory.json](model/report_inventory.json).

See [the dashboard guide](../docs/powerbi_dashboard.md) for page purposes, slicers, navigation, drill-through, tooltips, metrics and limitations. [Native acceptance](../docs/dashboard_demo_checklist.md) remains pending. Preview images are Python-rendered design reviews, not native screenshots.
